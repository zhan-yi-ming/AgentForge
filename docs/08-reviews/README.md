# 08-reviews: 代码审查中心

本目录保存由 Pi Agent (DeepSeek) 执行的代码审查报告与主开发 (Codex) 的修复评估闭环记录。

## 审查流转机制

1. **触发时机**：Codex 每完成一个阶段并交付（或在阶段中断点），自动触发 Pi Agent 执行只读代码审查。
2. **审查报告**：Pi Agent 读取当次交付的 `git diff`、相关代码与测试，按照 `../templates/review-record-template.md` 格式生成报告，命名规范为：
   `YYYY-MM-DD-review-day-<X>.md`。
3. **修复与回填**：Codex 读取审查报告，对提出的问题做出技术研判：
   - 若采纳：实施修复并补充自动化测试，在报告第 3 节回填修复说明；
   - 若误报或豁免：在第 3 节明确写出技术依据与原因；
   - 严禁盲目机械照改。
4. **归档**：双方确认无阻断性问题后，将报告状态更新为 `RESOLVED`。
