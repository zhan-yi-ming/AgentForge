# 完成标准

- 状态：Accepted

一项变更只有同时满足以下条件才算完成：

- 变更记录存在，且背景、范围、实现和验证不是空白。
- 受影响的产品、架构、功能、API、开发或运维文档已经先更新。
- 重要取舍已经写入 ADR。
- 实现没有超出文档声明的范围。
- 新增或变化的行为有相称的自动化测试；无法测试的部分有原因和人工验证方法。
- 构建与测试结果按真实情况写入变更记录。
- 日志和错误信息足以定位失败环节，且不泄漏敏感信息。
- 配置通过环境变量或显式配置提供，不把密钥写进仓库。
- 文档链接、目录和命令可用，未来状态与已实现状态没有混写。
- 已创建表达本阶段完整意图的 Git 提交。
- 提交后已停止开发，并向用户汇报完成事项、验证、可选介入项和下一阶段计划。
- 下一阶段尚未开始，正在等待用户明确确认。
