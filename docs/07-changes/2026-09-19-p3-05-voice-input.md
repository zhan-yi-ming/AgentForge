## 需求与方案

聊天页加入按下录音、停止、查看实时转写、编辑和主动发送。阿里云录音文件 HTTP API 要求文件 URL 并异步轮询，不适合即时输入；采用官方 Qwen3-ASR-Flash-Realtime WebSocket API 的 PCM 16 kHz 流。浏览器录音降采样并通过已认证的 Core API 小块上传，同时短轮询转写；Core 每次校验项目权限并转发，Python Agent Service 持有服务端配置的阿里云密钥与 WebSocket 会话。浏览器只接收文字，不收到密钥或上游 URL。用户停止时发送 `session.finish`，等最终结果再放入可编辑输入框，不自动触发 Chat。

会话 ID 绑定 project/user，内存临时保存转写状态，不保存原始音频或将其写入聊天历史。录音长度、块大小、总字节、空闲时间有限制；切路由、切项目和卸载时中止采集并取消会话。密钥缺失、麦克风拒绝或上游失败以非敏感错误提示，不妨碍文字聊天。新功能只在独立 `/chat` 页面使用，不给其它路由增加录音代码执行成本。

官方依据：[实时交互流程](https://help.aliyun.com/zh/model-studio/qwen-asr-realtime-interaction-process)、[客户端事件](https://help.aliyun.com/zh/model-studio/qwen-asr-realtime-client-events)、[录音文件 HTTP API](https://help.aliyun.com/zh/model-studio/fun-asr-recorded-speech-recognition-http-api)。
