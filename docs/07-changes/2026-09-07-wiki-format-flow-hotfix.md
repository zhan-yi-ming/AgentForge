# Wiki AI 整理流程热修

## 状态

Implemented

## 背景与生产证据

AI 文本整理结果可能被模型整体包在 `markdown` 代码围栏中，现有 Markdown 预览会把全文渲染成深色代码块并产生横向溢出。点击“应用到 Wiki 草稿”仅更新状态，没有滚动定位或可见反馈；Wiki 保存成功同样没有成功提示，造成“卡住或接口失败”的感受。

针对用户提供的页面，生产 gateway 最近三次 Wiki `PUT` 与后续列表 `GET` 均返回 200；只读查询显示当前页面版本为 3、内容长度为 1894。因此本次不修改 Java Wiki API、数据库或乐观锁契约。

## 目标与范围

- AI 整理结果若且仅若被一个完整的外层 Markdown 代码围栏包裹，则移除该围栏后再预览和应用；正文内部代码块保持不变。
- 预览中的代码块必须在容器内换行或局部滚动，不再撑宽整页。
- 点击“应用到 Wiki 草稿”后滚动到 Wiki 工作台的编辑位置，并显示明确的已应用提示。
- Wiki 保存成功后显示明确的保存成功提示；请求失败继续显示 Problem Details，不伪造成功。
- 不修改 Agent、Core API、数据结构、TLS 或部署架构。
