# 固定顶栏后的内容偏移修复

- 日期：2026-09-09
- 状态：Completed
- 阶段：V2 发布后样式修复
- 交付目标：本地预览确认后发布生产

## 背景

顶栏改为 `position: fixed` 后脱离 Grid 排版流，主工作区仍被自动放入第一行，导致首页欢迎区、工作台导航和 Wiki 内容被 76px 顶栏覆盖并挤压。

## 目标

主工作区明确进入顶栏下方的 Grid 第二行；左侧悬浮导航、抽屉及聊天工具窗以顶栏以下的可视区域居中，所有页面内容保持原有比例和间距。登录页按用户提供的视觉参考改为品牌介绍与登录卡片双栏布局，并重新设计聊天输入框的展开按钮。

## 非目标

不修改接口、数据、测试或后端；用户本地确认前不提交、不推送、不部署生产。

## 受影响文档

- `docs/03-features/web-workspace.md`：补充固定顶栏的布局占位约束。

## 实现

- 主工作区固定到 Grid 第二行，从 76px 固定顶栏下方开始排版。
- 左侧悬浮导航、抽屉和聊天工具窗按顶栏以下的剩余视口重新居中并限制最大高度。
- 对话模式工具栏下移到顶栏安全区之外。
- 登录入口改为桌面双栏、窄屏单栏的品牌展示与登录卡片，并加入轻量几何背景。
- 聊天展开按钮改为紧凑圆角方形控件，图标使用 Flex 居中并统一可视尺寸。

## 验证结果

按用户要求不修改或运行自动化测试；本地 Vite 预览已启动，首页请求返回 HTTP 200。用户已完成本地人工验收，并明确授权直接部署生产。

## 风险与回滚

风险仅限前端纵向布局。回滚时移除本次 CSS 覆盖即可。
