# ADR-0002：使用单仓库维护多个可部署应用

- 状态：Accepted
- 日期：2026-09-03

## 背景

V1 同时包含 React Web、Java Core API、Python Agent Service、Compose 和共同文档，接口会高频协同变化。

## 备选方案

- 每个语言单独仓库：边界强，但 V1 契约更新、联调和追溯成本更高。
- 一个目录混放所有代码：起步快，但构建、职责和部署边界模糊。
- 单仓库、多应用目录：共享历史与文档，同时保留独立构建边界。

## 决策

采用 `apps/web`、`services/core-api`、`services/agent-service`、`infra`、`docs` 的单仓库结构。每个应用独立管理依赖和运行入口。

## 结果

一次变更可以原子地更新契约、实现和文档；根目录提供统一入口。需要通过目录规则避免跨应用源码耦合。

## 取代关系

无。
