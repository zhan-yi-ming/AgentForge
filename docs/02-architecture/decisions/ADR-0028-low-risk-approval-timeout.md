# ADR-0028：低风险审批的限时自动确认

- 状态：Accepted
- 日期：2026-09-20
- 关联：ADR-0021、P3-06

## 背景

V2-06 的所有 Agent Task Action 均等待用户确认。P3-06 需要悬浮确认表单默认 60 秒，高风险操作不得超时自动通过。前端计时器不可信，也可能暂停或关闭；模型不得提供可信风险或审批字段。

## 决策

只为 Java Tool Policy 当前标为 LOW、且明确列入自动确认白名单的 `CREATE_TASK` 开放专用 `auto-confirm` 入口。Java 在已认证 actor/project 范围内锁定持久化提案，复核 Tool Policy、`PENDING` 状态及 `created_at + 60s`，然后使用 V2 既有幂等审批、Agent resume、业务执行和审计事务。审计新增 `AUTO_APPROVED` 类型，迁移数据库事件类型约束；手动确认继续记录 `APPROVED`。MEDIUM/HIGH 风险无自动确认入口能力。前端从弹窗打开起计满 60 秒、仅在弹窗仍打开时发送请求，关闭页面不会留下后台任务。

## 结果与取舍

时钟和风险最终由 Java 决定，重复请求不能重复写入；浏览器离线或关闭时不会自动批准，用户重新打开页面仍可手动处理。新增审计枚举与迁移需要 L3 验证，但不更改 V2 审批终态和 Python/Java 边界。
