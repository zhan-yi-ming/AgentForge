# ADR-0004：数据库结构使用版本化迁移

- 状态：Accepted
- 日期：2026-09-03

## 背景

自动根据 JPA Entity 更新数据库无法可靠审查删除、约束和索引变化，也不能清楚复现环境历史。

## 备选方案

- Hibernate `ddl-auto=update`：本地方便，但不可控且缺少可审阅历史。
- 手工执行零散 SQL：明确但容易漏环境，也无统一状态。
- Flyway 版本化迁移：迁移与代码共同版本管理，启动时按顺序执行。

## 决策

使用 Flyway；JPA 配置为 `ddl-auto=validate`。共享过的迁移不可修改，通过新版本修正。

## 结果

schema 变化可追溯、可复现，启动会及早发现 Entity/数据库偏差。团队需要认真评估不可逆迁移并记录回滚或前滚方案。

## 取代关系

无。
