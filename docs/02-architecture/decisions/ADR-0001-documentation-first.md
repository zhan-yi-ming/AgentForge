# ADR-0001：文档先行作为强制开发顺序

- 状态：Accepted
- 日期：2026-09-03

## 背景

项目主要由 AI 搭建。对话上下文易丢失，单靠代码和提交信息不足以解释产品、边界、失败模式和历史原因。

## 备选方案

- 开发后补文档：速度看似快，但文档容易遗漏或只描述结果。
- 只依赖代码和 Git：能看到差异，难以恢复设计意图。
- 文档先行：增加少量前置成本，但让设计、实现和验证形成证据链。

## 决策

采用文档先行，并写入根目录 `AGENTS.md`。每次变更先创建记录和更新目标文档，再修改实现，最后回填验证。

## 结果

任何开发代理都有明确顺序；用户可先审设计再审代码。代价是小改动也需要记录，但允许同主题的小修正合并到一份记录。

## 取代关系

无。
